# LaurentGM

Site web officiel et plateforme professionnelle du **Cabinet de Conseil en Innovations Technologiques, IA & Stratégie Opérationnelle** dirigé par **Laurent G-M Manouaba**.

## 🚀 Présentation
- **Vision** : « La technologie révolutionnaire à la portée de tous »
- **Aesthetics** : Design blueprint moderne sur fond blanc pointillé, typographie Outfit & Plus Jakarta Sans, animations de transition fluides, zéro label au-dessus des titres.
- **Expertises** : 12 Services de pointe (Intelligence Artificielle, Machine Learning, Datafication, R&D de rupture, Audit de réduction de coûts, Eustress management).
- **SEO & Référencement** : Données structurées Schema.org JSON-LD (Person, ProfessionalService, FAQPage, OfferCatalog), métadonnées OpenGraph et Twitter Cards, sitemap.xml et robots.txt configurés.

## 🛠️ Stack Technique
- **Framework** : React 18 + Vite
- **Icônes** : Lucide React
- **Styles** : CSS Vanilla & Design System sur-mesure (sans dépendances externes superflues)
- **Intégrations** : Réservation WhatsApp instantanée avec pré-remplissage de message, deep linking hash routing.

## 📦 Installation & Démarrage local
```bash
# Installation des dépendances
npm install

# Lancement du serveur de développement (localhost:3000)
npm run dev

# Compilation de production
npm run build
```
